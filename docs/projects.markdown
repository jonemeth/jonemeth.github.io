- **[llama3.cpp](https://github.com/jonemeth/llama3.cpp)**: Llama 3 inference in pure
  C++20 with float32 and int8 quantized weights.
  [Read the write-up]({% post_url 2025-04-21-llama3.cpp %}).
- **[CategoricalDiffusion](https://github.com/jonemeth/CategoricalDiffusion)**: an
  experimental implementation of *Denoising Diffusion Probabilistic Models* using
  categorical variables.
- **[Transformers](https://github.com/jonemeth/Transformers)**: a playground for
  transformer-based vision models (ViT, Swin).
- **[MandelbrotZoom](https://github.com/jonemeth/MandelbrotZoom)**: a Mandelbrot zoom
  implemented on both CPU and GPU.
- **[generative-models](https://github.com/jonemeth/generative-models)**
- **[latent-diffusion](https://github.com/jonemeth/latent-diffusion)**
- **[RayTracing](https://github.com/jonemeth/RayTracing)**
